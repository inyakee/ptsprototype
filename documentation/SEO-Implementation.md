# SEO Implementation

## Metadata

Each page includes:

- Unique title
- Meta description
- Canonical URL
- Open Graph metadata
- Twitter card metadata

## Structured Data

The home page includes `MedicalClinic` schema with:

- Clinic name
- Phone
- Fax
- Email
- Address
- Hours
- Medical specialties

The services page includes FAQ schema.

## Local SEO

Local signals are repeated consistently:

- Physical Therapy Services
- 1310 Coburg Rd #5, Eugene, OR 97401
- (541) 345-7532
- info@ptsclinic.com

## URL Mapping

- `/` -> `index.html`
- `/about` -> `about.html`
- `/services` -> `services.html`
- `/massage-therapy` -> `massage-therapy.html`
- `/our-team` -> `team.html`
- `/new-patients` -> `new-patients.html`
- `/contact-address-hours` -> `contact.html`
