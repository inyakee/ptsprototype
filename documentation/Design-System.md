# Design System

## Brand Feel

Professional, caring, family-oriented, trustworthy, experienced, and welcoming.

## Colors

- Primary blue: `#0f5f8f`
- Dark blue: `#0a3c5d`
- Teal: `#22a6a1`
- Coral CTA accent: `#f26d5b`
- Soft background: `#f4f9fb`
- Text: `#334155`

## Typography

- Headings: Poppins
- Body: Inter
- Fallback: system UI

## Components

- Sticky header with mobile hamburger navigation
- Rounded cards with 8px radius
- CTA buttons
- FAQ accordions
- Testimonial slider
- Responsive grids
- Sticky mobile call/book actions
