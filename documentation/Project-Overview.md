# Project Overview

This redesign modernizes the Physical Therapy Services website into a responsive, accessible, SEO-focused healthcare site.

## Goals

- Improve patient trust and make clinic contact paths clearer.
- Preserve current clinic content, including services, team information, contact details, hours, and new-patient guidance.
- Support mobile users with click-to-call, sticky navigation, and a persistent call action.
- Provide PHP form processing compatible with shared hosting.
