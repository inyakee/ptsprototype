# Maintenance Guide

## Monthly

- Test the contact form.
- Check SMTP delivery and spam folders.
- Review pages for outdated pricing or hours.
- Verify mobile layout at 375px and 768px.

## Quarterly

- Run Lighthouse for performance, accessibility, SEO, and best practices.
- Review staff bios and credentials.
- Update massage pricing if the clinic changes rates.
- Confirm Google Maps and social links still work.

## Security

- Keep SMTP credentials private.
- Restrict file permissions for `backend/smtp-config.php`.
- Update PHPMailer when security releases are published.
- Keep PHP at a supported version.
